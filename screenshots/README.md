# Screenshots

This directory contains screenshots of the game for the README.

To add screenshots:
1. Run the game: `python main.py`
2. Take screenshots of:
   - Main menu (save as `menu.png`)
   - Gameplay in action (save as `gameplay.png`) 
   - Victory screen (save as `victory.png`)
3. Place the PNG files in this directory

The README.md file references these screenshots to showcase the game's features.
